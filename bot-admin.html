Painel privado do bot

Página separada do painel público. Não contém cupões pré-carregados nem revela códigos aos clientes.

Autenticação do administrador

A proteção real depende do backend. Não coloques tokens ou palavras-passe neste HTML.

Gerir cupões

Cria códigos que só o bot aceita. Para a oferta de dois anos, define 730 dias. O código é guardado no servidor, não no site público.

Resgatar código recebido pelo bot

O cliente envia o código no chat privado do bot. O bot valida no servidor e ativa o plano, sem o publicar na página dos clientes.

Endereço desta página: /bot-admin.html. O facto de não haver um link no menu não é segurança: todas as operações precisam de autenticação e validação no servidor.
